# 全站左右滑动防误触

用户要求避免左右滑动触发浏览器返回/前进，明确不只限于游戏。覆盖单页乐园的首页、学科、答题、古诗和弹窗，以及独立游戏页面；沿用本地修改、暂不部署的要求。

使用共用 CSS 限制横向边界导航，配合非被动的横向 wheel/touch 事件拦截。保留纵向滚动、缩放、输入控件和页面返回按钮；古诗标签、题号条等内部横向容器改为在本容器内消化位移，到边缘时不把动作传给浏览器。保留浏览器正常历史记录，不添加循环历史项或离开确认。
