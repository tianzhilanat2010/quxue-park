# 首页四个主入口的插画与动画

用户要求通过 Chrome 中的 ChatGPT 制作精美 GIF，改善首页数学、语文、英语和趣味游戏四个大卡片。优先在已登录 ChatGPT 网页制作，先检查实际产物再接入。保留当前 2 × 2 入口和各入口功能。

统一视觉：精致 3D 卡通、蓝色博士帽的熊猫博士、温暖自然光、奶油色与植物绿的环境。使用横向画面，文字标题在网页中排版。

- 数学：数字积木花园，熊猫手部摆放积木、看积木与眨眼。
- 语文：春日书院、展开的故事书，熊猫翻页，纸页有弯曲过程。
- 英语：字母花园和动物伙伴，角色自然互动与说话口型。
- 游戏：浮空小岛跳跃和海底小鱼，身体起跳、落地缓冲。

动画验收：镜头固定，角色或物件有独立姿态变化，避免整张图缩放平移替代动作。真实多帧，循环首尾自然，无明显闪烁、人物变形。网页素材保留静态封面，响应已有暂停动画与减少动态效果设置；GIF 另存交付，页面可使用画质相同的轻量格式。

执行记录：已在 Chrome 新建 ChatGPT 会话“制作数学动画卡片”，发送首张样片需求。待实际生成结果决定后续素材处理，不把静态文件改扩展名伪装为动画。
