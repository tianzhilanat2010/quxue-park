# 阅读小书房实现计划

**目标：** 按已确认方案，为二年级语文加入 12 篇原创短故事、纸质书阅读记录、可增减的好词好句与阅读体会、浏览器自动保存和打印阅读卡。本次完成本地版本，不部署。

**结构：** 沿用现有单页视图切换，在语文页增加独立入口。新内容、记录数据及界面放在单独模块，避免继续扩充题库内联脚本。中文朗读使用刚调整的女声服务。

**技术：** 原生 HTML / CSS / JavaScript，localStorage，现有 MiniMax 流式播放器，Node 内置测试。
