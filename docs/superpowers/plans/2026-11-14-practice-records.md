# 浏览器练习记录

为 A–H 数学卷保存完整交卷快照，在首页及试卷页提供“练习记录”，在选卷菜单显示完成次数、最近成绩与未完成进度。记录详情按小题展示当时题目、自己的答案、正确答案及讲解；重做不覆盖历史，查看历史不重复加星或计入完成数。

未交卷答案自动保存，重新进入同一套卷继续作答，恢复已用时间和可选倒计时。普通数学、语文、英语闯关交卷时也保留题目及答案，可从同一入口复习。

使用独立 localStorage key，保存所有交卷记录；缓存损坏、禁用或写满时显示保存提示并保持做题可用。记录仅属于当前浏览器及网站域名，旧版本没有保存的卷面无法补回。

实施顺序：先写记录存储、逐题复习和恢复计时测试；实现独立存储及记录面板；接入交卷、自动保存及入口；执行相关测试及本地浏览器刷新验证。此次先完成本地修改。
