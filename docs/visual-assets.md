# 首页动态素材

来源：用户指定的 [ChatGPT 网站会话](https://chatgpt.com/c/6aec3abe-a0e4-83ec-82db-07f5628c7a70)。

## 角色动画

要求：单只毛绒 3D 熊猫博士、蓝色博士帽与圆眼镜，固定镜头和浅薄荷背景。角色抬手、挥手、眨眼、放下手臂，避免整幅插画平移。

从网页下载实际生成的 GIF，并逐帧检查 12 个姿势：第 6 帧闭眼，其余帧有抬手、挥手与收手变化。角色有轻微姿态变化，属于 12 帧循环动画，不是高帧率视频。

- `design/source/panda-wave.gif`：原始下载文件，357×358，12 帧，每帧 250ms，3 秒循环。
- `assets/panda-wave.webp`：保留原始姿势与时长，转换为 animated WebP，约 178 KiB。
- `assets/panda-wave-cover.webp`：第一帧静态封面，约 16 KiB。
- `assets/game-cover.webp`：同一会话生成的星空冒险插画，600×360；游戏入口的星光使用局部 CSS 动画。

网页可切换为静态封面来暂停角色动画，同时暂停局部装饰。偏好保存于浏览器，默认尊重系统减少动态效果设置。
