# 阅读小书房

2026-11-14 实现并已发布至 <https://math-wonderland.netlify.app/>。本地预览 <http://localhost:5205/>，从首页进入“二年级语文乐园”，点击“阅读小书房”的“翻开一本小故事”。当前工作分支 `codex/reading-notebook`，保留工作区原有未提交修改。

## 使用方式

书架内有 12 篇原创短故事，可按童话、校园、家庭、自然筛选。每篇约 239–255 汉字，正文分成四段，支持整篇或按段朗读，使用网站已有中文女声音色。好词提示提供拼音和释义；句子提示摘自原文，附一个思考问题。点击收藏后加入阅读卡的空白位置，不重复收藏同一条内容，也不会预填孩子的体会。

“记录纸质书”可填写书名、作者、阅读日期、篇目/章节/页码，接着手动输入摘录与体会。站内和纸质书记录采用相同格式；每条好词、好句都能补充理解、造句或喜欢的理由，属于选填。初始提供三个好词位置和两个好句位置，均可自由增减，没有固定数量要求。

“我已经读完这一篇 / 这一章”与“完成阅读卡”分开记录。完成阅读卡需要书名、已读标记、至少一条好词、一句好句和自己的体会；不足时保留草稿，提示还可以补什么，不按字数、关键词或标准答案评分。阅读本可筛选全部、接着写、已完成，支持重新打开修改；“再记一张”可为同一本书或故事建立另一条记录。

输入后延迟 250ms 保存；离开阅读视图、隐藏或关闭页面时立即保存。重新打开书房时提供最近未完成记录的继续入口，书架也显示对应的阅读状态。页面刷新后沿用全站行为先回首页，再进入书房即可恢复。缓存不可读或写入失败时明确提示，保留当前输入，避免站内切换丢失尚未保存的内容。

点击“打印阅读卡”仅打印当前记录，包含书名、作者、日期、篇目、姓名班级留白、好词好句、自己的补充和体会；不把网站导航、故事原文和其它阅读记录一同打印。可通过浏览器打印窗口另存 PDF。取消打印后恢复原页面。

## 文件与数据

- `assets/reading-library.js`：12 篇正文、主题、封面符号、好词的拼音释义、原文好句、体会引导问题。
- `assets/reading-notebook.js`：记录创建、摘录去重、完成条件、存储与打印转义。
- `assets/reading-room.js`：书架、阅读及填写页、记录本、自动保存与朗读按钮。
- `assets/reading-room.css`：纸张与故事封面样式、手机排版、独立打印样式。
- `index.html`：语文入口、阅读视图、视图切换时保存、模块初始化、独立打印容器。

localStorage key 为 `panda_reading_notebook_v1`，格式 `{version:1, entries:[...]}`。每条记录有独立 id，保存来源、故事 id、书名/作者/篇目/日期、已读状态、带 id 的词句摘录及笔记、体会、草稿/完成状态、创建/更新时间。阅读数据独立于数学试卷与普通闯关记录，不写服务器。朗读按钮只发送所选故事正文给现有语音接口。

数据只属于当前网站域名和浏览器。本地预览、正式 Netlify 域名、其它设备各自独立；清除网站数据后无法恢复。没有为了腾空间而自动淘汰旧阅读卡。
