# 熊猫博士跳跳乐 · 2026-11-09

将原星际赛博游戏改为与首页一致的奶油白、薄荷绿卡通花园。角色由可编辑的 Three.js 圆润网格组成，包含圆眼镜、博士帽、披风和星星徽章。支持天空蓝、薄荷绿和蜜桃粉三套配色。

动作包含呼吸、眨眼、起跳蓄力、空中伸展与落地缓冲，镜头以能看清面部的角度跟随。原数学题库、五选项、计分、限时和选项重排保留。答错改为温和提示与返回动作，移除雷击、碎屏与剧烈摇晃。打开设置或隐藏页面时暂停倒计时。

- `games/cyberhop.html`：入口与原题库、答题状态。
- `games/panda-world.js`：模型、关节动画、树木云朵。
- `games/panda-game.css`：桌面与手机界面。
- `games/panda-cover-preview.html`：使用游戏模型渲染首页封面的编辑工具，点击按钮导出 PNG。
- `assets/panda-garden-cover.webp`：实际模型渲染的首页封面。
- `games/vendor/three.min.js`：固定 r128 依赖，随站点提供；许可证在同目录。

验证：`node --test scripts/panda-game.test.mjs`，覆盖角色姿势变化、答对推进、答错返回、切换题型时取消旧回调、换装位置保留、暂停计时。浏览器实际检查桌面跳跃和 390px 手机布局；未运行全站测试。
