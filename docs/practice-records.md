# 浏览器练习记录

2026-11-14 新增，已随阅读小书房发布至 <https://math-wonderland.netlify.app/>，发布编号 `6af7f78c07018617c0b20c93`。

首页“我的练习记录”、数学试卷工具栏“练习记录与错题”和普通闯关成绩页“历次成绩与错题”均打开同一记录面板。A–H 每套显示未做、完成次数、最近成绩、最高成绩和未完成答卷；选卷菜单也显示完成状态。点击历史记录默认只看错题，可切换全部题目。

每次交卷独立保存当时题目、学生答案、成绩、完成时间、答题用时。计算题按小题收录，应用题保留列式及答语；重做不覆盖旧记录，查看记录不重新评分或加星。普通数学、语文及英语闯关保存实际生成的整套题目，后续出题变化不会改变旧答案。已有动画讲解使用该条记录的题目数据；口算及混合运算详情直接显示当前小题正确算式。

数学 A–H 卷输入后自动保存草稿，切换试卷、离开页面或隐藏页面时立即保存。重新进入同套卷会恢复原答案、已用时间和可选挑战的剩余时间；离开期间不计时。清空全部答案后移除本次草稿。已经交卷的试卷只读，旧标签页不会再创建已完成答卷的草稿。

存储模块为 `assets/practice-records.js`，界面和样式为 `assets/practice-records-ui.js`、`assets/practice-records.css`。localStorage key：`panda_practice_records_v1`，版本 1；结构包含按试卷模式区分的 `drafts` 和所有交卷快照 `attempts`。保存失败会明确提示；不会为腾出空间而静默删除旧记录。普通闯关仅保存交卷记录，未交卷草稿仅用于固定数学卷。

仅保存在当前网站域名、当前浏览器的数据中，不上传服务器。清除网站数据、使用另一浏览器或更换设备无法继承；本地预览与 Netlify 域名各自独立。旧版本没有保存过的详细作答无法补回，记录从此功能启用后开始。

验证：记录存储、恢复计时与原数学卷批改共 21 项定向测试通过；新增模块与内联脚本语法检查通过。Safari 实际检查 C 卷输入 `52`、`99` 后刷新可恢复；交卷再刷新仍显示已完成及 1 分；错题显示 `99` 与正解 `51`，全部题目中正确作答仍为 `52`；记录中的搬萝卜动画沿用 C 卷 `18 ÷ 3`；普通 5 题闯关交卷并刷新后也可查看原题；390 × 844 手机尺寸的详情、筛选与答案排版正常。未运行全量测试或整站构建。
