# 背景音乐

《森林小漫步》为本项目编排的纯器乐合成配乐，没有使用第三方录音或采样。78 BPM、16 小节、约 49 秒循环；音色为柔和钟琴、拨弦与低音和弦。音频保存为 `assets/audio/forest-stroll.mp3`，约 674 KiB。

首页、数学练习及动画课堂共用页头音乐开关。首次访问默认关闭，点击后播放；偏好与音量保存在当前浏览器。返回访问时可在首次交互后恢复。原有音效和语音开关独立控制。星际跳跃是独立页面，保留其原有游戏音效。

读题期间音乐降至所选音量的 18%，结束后恢复；隐藏页面或离开时暂停。系统阻止播放或加载失败时，可再次点击音乐按钮重试。没有把浏览器自动播放限制视为成功播放。

- 控制逻辑：`assets/music.js`，使用 HTML Audio 循环及 Web Audio GainNode 调节音量。
- 重制音乐：安装 NumPy 和 FFmpeg 后执行 `python3 scripts/render-music.py`。普通网站构建不需要生成音频。
- 定向验证：`node --test scripts/music.test.mjs`，覆盖主动开启、音量保存、读题降低音量、后台暂停、播放失败与快速切换。
