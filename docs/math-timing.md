# 数学答题时间

数学普通练习与 A4 模拟卷默认不限时：继续记录用时，超过 20 分钟也不会自动交卷。在首页模拟考入口、数学岛以及答题页的“做题时间”选项，可主动改为“20 分钟挑战”。

切换为限时挑战时，从切换时刻开始完整 20 分钟倒计时；切回不限时时取消截止时间，已填答案与累计用时保留。同一页面会同步选择，重新打开网站恢复默认不限时。语文、英语练习继续只记录用时。

`assets/practice-timing.js` 提供共用计时器；页面在开始新练习、交卷或换卷时停止旧计时器。A4 试卷正文和打印出的时间说明与实际模式一致。

定向验证：`node --test scripts/practice-timing.test.mjs`，覆盖不限时超过 20 分钟、可选挑战自动交卷一次、取消限时、保留用时/答案以及实际试卷和练习入口。浏览器验证默认模式与切换后答案保留。
